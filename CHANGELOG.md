# Changelog

## 1.0.0

- Added normalized objects, root-scoped schema version 1, granular capabilities, validated settings and independent feature flags.
- Added graph, topics, voluntary onboarding, deterministic personalized feeds, feedback, discovery, search and provider interfaces.
- Added questions, accepted answers, helpful votes, reviewed knowledge and an auditable topic reputation ledger with acceptance reversal.
- Added reports, consolidated cases, evidence, internal audits, restrictions, warnings and controlled appeals.
- Added durable background jobs, typed automations, dry runs, bounded retries, consent-based metrics, defined health indicators and experiments.
- Added optional public-text intelligence requests, bounded transport, DNS pinning and failure backoff.
- Added BuddyPress hooks, REST v1, progressive enhancement, dynamic blocks, privacy export/erasure, RTL styles and translation catalog.
- Added integration, security, browser, accessibility, compatibility, Multisite and performance tooling. Release verification scope is recorded in the engineering report.
